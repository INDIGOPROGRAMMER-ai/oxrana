# Дорожная карта

Один этап = одна сессия Claude Code (полдня–день). У каждого — состав, критерий готовности и номера сценариев приёмки (`docs/spec/14_…` 1–32, `16_…` раздел C 33–44; сценарий 31 заменён 42), которые он закрывает автотестами. Этап считается закрытым, когда typecheck, lint и все тесты зелёные, статус обновлён здесь, а новые решения — в ADR.

Статусы: ⬜ не начат · 🟨 в работе · ✅ готов.

## Правила ведения

- Демо-объект (сид) — только для тестов и разработки; реальный сервер стартует чистым, объект настраивает заказчик через интерфейс (ADR-016).

- Этап начинается с короткого плана в начале сессии и заканчивается обновлением статуса здесь, записью новых ADR и отчётом по формату `CLAUDE.md`.
- Сценарий считается закрытым, когда есть автотест с его номером в названии (`it('сценарий 37: гонка за последнее место', …)`).
- Если этап не влезает в сессию — он делится на `Na`/`Nb` здесь же, а не растягивается молча.
