# Словарь терминов

Правило: **одно понятие — один русский термин в интерфейсе и один идентификатор в коде.** Синонимы из ТЗ и PASS24 перечислены в последней колонке только для того, чтобы их **не** использовать.

> Q-42 закрыт (10.10.2026, вариант «а»): в интерфейсе и документах — **«тип транспорта»** и **«лимит»**; в коде — `vehicle_category` и `quota`. Слова «категория транспорта» и «квота» остались только в ТЗ (`docs/spec/`, `docs/reference/`) и договорах: читать как «тип транспорта» и «лимит», в новых текстах не использовать. ТЗ под новые термины не правится — словаря достаточно (решение заказчика 10.10.2026, Q-45).

## Объект и инфраструктура

| Термин в интерфейсе | В коде | Что это | Не использовать |
|---|---|---|---|
| Организация | `organization` | Оператор-клиент платформы (ООО «Интеграция»). Корень мультиарендности | аккаунт, компания |
| Объект | `site` | Охраняемая территория (ЛЦ «Радонежский») со своим часовым поясом | комплекс, площадка |
| Зона | `zone` | Здание или участок территории: склад, стр. 5, АБК, парковка | здание (как сущность) |
| КПП | `gate` | Пост пропуска. Полностью настраиваемый: вид (`kind`), кого пропускает (`admits`), матрица типов (маршруты). Про конкретный объект в коде ничего нет | пост, чекпойнт, checkpoint |
| Кого пропускает | `gate.admits` | `vehicles_and_pedestrians` (машины и пешеходы) · `vehicles` (только машины) · `pedestrians` (только пешеходы) | фильтр КПП |
| КПП периметра | `gate.kind = 'perimeter'` | Открывает и закрывает визит на территорию | |
| Внутренний пост | `gate.kind = 'internal'` | КПП офис: отмечает проход, визит не трогает | |
| Док | `dock` | Пронумерованные ворота разгрузки (№1–72) | ворота, рампа |
| Парковочный участок | `parking_area` | Участок стоянки с числом мест | парковка |
| Рабочее время объекта | `site.working_hours` | Часы, когда действует обычный въезд | режим работы |

## Участники и справочники

| Термин | В коде | Что это | Не использовать |
|---|---|---|---|
| Участник | `participant` = `vehicle` \| `pedestrian` | Кто проходит: машина или пешеход | тип гостя |
| Пешеход | `pedestrian` | Участник без транспорта. Не «машина без типа» | посетитель, гость |
| Тип транспорта | `vehicle_category` | Справочник организации с переопределением на объекте: рекомендованный набор включается кликом, свои типы, переименование, порядок перетаскиванием, выключение. Спецтехника — обычный тип со своим лимитом | категория (как термин интерфейса), тип ТС, класс |
| Рекомендованный тип | `vehicle_category.preset_code` | Запись из встроенного списка `VEHICLE_CATEGORY_PRESETS` (легковой, малотоннажный, фура, грузовой свыше 5 т, спецтехника, автобус, мототехника…) | дефолтный тип |
| Набор типов лимита | `quota_categories` | Какие типы транспорта считает лимит: «Грузовые» = малотоннажный + фура + грузовой свыше 5 т. Отдельной сущности «группа» нет (ADR-012) | группа категорий, группа типов, class |
| Цель визита | `visit_purpose` | Разгрузка, погрузка, гость… с нормативом времени | опция |
| Норматив времени на территории | `visit_purpose.max_stay_minutes` | Сколько можно находиться без предупреждения | лимит времени |
| Номер (ГРЗ) | `plate` | `plate_raw` — как ввели; `plate_norm` — нормализованный; `plate_country` | госномер, регномер |
| Иностранный номер | `plate_country ≠ 'RU'` | Номер по маске другой страны или не распознанный | |
| Чёрный список | `blacklist` | Номера и люди, которым отказано | стоп-лист |

| Назначение дока | `tenant_dock_assignment` | Док закреплён за арендатором на срок | привязка |
| Назначение мест | `tenant_parking_assignment` | Места на участке закреплены за арендатором | |
| Пользователь арендатора | `user` + `role_assignment.tenant_id` | Логист, диспетчер, ответственный | сотрудник арендатора |
| Ответственный арендатора | роль «Арендатор — ответственный» | Получает запросы с поста, управляет своими пользователями | |
| Автопарк | `fleet_vehicle` | Постоянные машины арендатора — шаблоны для заказа | |
| Правила для пешеходов | `pedestrian_rule` | Документ обязателен / сопровождение / телефон / текст для охраны | |
| Грузовые только к докам | `tenant.trucks_dock_required` | Настройка: у грузового пропуска док обязателен | |

## Правила

| Термин | В коде | Что это | Не использовать |
|---|---|---|---|
| Лимит | `quota` | Сколько машин выбранных типов (или пешеходов) может быть на территории одновременно у арендатора. В форме: «[типы] — [число] · режим · основание» | квота, адрес |
| Вместимость | `quota.capacity` | Число мест в лимите. `0` = «не предусмотрено договором» | лимит (это сам набор «типы + число»; число — вместимость) |
| Занятость | `occupied` | Открытые визиты, попадающие в лимит | заполненность (в табло допустимо как заголовок) |
| Режим лимита | `quota.enforcement` = `hard` \| `soft` \| `warn` | Жёсткий (не пускать) · мягкий (пускать сверх с начислением) · информирующий | строгость |
| Способ подсчёта | `quota.counting` = `on_site` \| `active_passes` \| `per_day` | По присутствию · по действующим пропускам · заездов в сутки | |
| Сверх лимита | `overage` | Визит, въехавший сверх мягкого лимита | превышение |
| Начисление за сверхлимит | `overage_charge` | Сутки × тариф по мягкому лимиту | доплата |
| Маршрут | `routing_rule` | Через какой КПП идёт (участник, тип транспорта) с переопределением для арендатора | фильтр КПП |
| Не тот КПП | вердикт `wrong_gate` | Пропуск есть, но этот КПП не разрешён маршрутом | «пропуска нет» |
| Окно прибытия | `pass.window_from / window_to` | Интервал, в который грузовая должна приехать | слот, временное окно |
| Политика окна | `time_window_policy` | Обязательность окна, допуск раньше `early_tolerance_min`, допуск позже `late_tolerance_min` | |
| Исключение | `exception` | Правило, снимающее проверки: автобус ДНС, X5 24/7, руководство | особый пропуск |
| Снимаемые проверки | `exception.waives[]` | `inspection`, `quota`, `time_window`, `working_hours`, `routing` | |
| Политика согласования | `approval_policy` | (роль создателя × тип пропуска) → `allow` \| `on_request` \| `deny` | режим одобрения |
| Согласующий | право `pass.approve` | Директор ЛЦ | аппрувер |
| Блокировка арендатора | `tenant.status` = `blocked_new_passes` \| `blocked_entry` \| `archived` | Режимы: новые пропуска запрещены · въезд запрещён · полная. Выезд разрешён всегда | |

## Пропуск и визит

| Термин | В коде | Что это | Не использовать |
|---|---|---|---|
| Пропуск | `pass` | Разрешение на въезд/проход | заявка (это другое), запрос |
| Разовый | `pass_type = 'single'` | До N часов, один въезд и один выезд, после выезда `used` | одноразовый, разовые |
| Многоразовый | `pass_type = 'multi'` | Любое число въездов в интервале (2 дня – 1 месяц) | **временный**, повторяющийся |
| Постоянный | `pass_type = 'permanent'` | Без срока окончания, закрывается вручную | бессрочный |
| Статус пропуска | `pass.status` | `draft` → `pending_approval` → `approved` · `rejected` · `cancelled` · `expired` · `used` | |
| Заявка на согласование | `pass.status = 'pending_approval'` | Пропуск, ожидающий решения согласующего | запрос |
| Одобрить с изменениями | `approve` + `changes` | Согласующий меняет поля и одобряет; изменения видны арендатору | |
| Заявка на изменение | `pass_change_request` | Арендатор просит изменить начавшийся согласованный пропуск | перевыпуск |
| Пакет | `pass_batch` | Пакетное создание: итог «создано N из M», построчные ошибки | импорт (это из PASS24) |
| Место назначения | `pass.destination_zone_id`, `pass.dock_id` | Куда едет: зона или док | адрес |
| Страница водителя | `pass_token` → `/p/{token}` | Публичная страница с QR, номером КПП, окном, схемой | страница приглашения |
| Визит | `visit` | Факт пребывания: въезд — выезд через КПП периметра | заезд, событие |
| Открытый визит | `visit.time_out is null` | Машина на территории. Единица подсчёта лимита | на территории |
| Въезд / Выезд | `check_in` / `check_out` | Действие поста, открывающее/закрывающее визит | «Приехал» / «Уехал» |
| Проход | `gate_passage` | Отметка на внутреннем посту; визит не меняет | |
| Выезд с отметкой | `check_out` + `flags: no_checkin` | Выезд без открытого визита, с причиной | |
| Пребывание после окончания | `flags: after_expiry` | Пропуск истёк, пока машина внутри | просрочка |
| Способ отметки | `visit.method` = `button` \| `qr` \| `lpr` \| `auto` \| `sync` | Кнопка · QR · камера · автопроезд · офлайн-синхронизация | |

## Вердикт и пост

| Термин | В коде | Что это | Не использовать |
|---|---|---|---|
| Вердикт | `verdict` | Результат проверки всех правил для пропуска на КПП в момент времени | решение, статус |

| Трассировка | `trace[]` | Список проверок с результатом: что проверено и чем закончилось | лог |
| Проверка | `check` | Один шаг движка: `blacklist`, `routing`, `time_window`, `quota`… | правило (это настройка) |

| Направить на КПП-2 | `redirect` | Действие при `wrong_gate`, пишется в журнал | |
| Отказать | `refuse` | Действие при `deny`, с причиной | |
| Ждать | `wait` | Состояние карточки при полном лимите или раннем прибытии | |
| Очередь у ворот | `gate_queue` | FIFO машин одного арендатора, ждущих место | |
| Машина без пропуска | `gate_request` | Запрос с поста арендатору/админу: оформить пропуск | |
| Запрос исключения | `override_request` | Запрос поста администратору впустить при 🟡/🔴. Одобрение = `override` | переопределение |

| Действие поста | `gate_action` | Въезд, выезд, отказ, «направить», отмена, проход — с id устройства: повтор с тем же id не выполняется второй раз (онлайн и из офлайн-очереди) | операция, событие |
| Табло | `occupancy` | Экран заполненности лимитов по арендаторам | дашборд |
| Песочница правил | `sandbox` | Проверка вердикта на произвольных входных данных в админке | тестовый прогон |
| Памятка | `cheatsheet` | Страница/PDF из настроек арендатора или КПП | инструкция |
| Что делать если | `help` | Встроенная помощь поста | |

## Учётки и устройства

| Термин | В коде | Что это | Не использовать |
|---|---|---|---|
| Пользователь | `user` | Только тот, кто входит в систему: сотрудник оператора или человек арендатора. Заводится приглашением и работает сразу. В форме пропуска поля «пользователь» нет: автор пишется автоматически | сотрудник (как сущность), «пользователь» как получатель пропуска (PASS24) |
| Автор пропуска | `pass.created_by` | Кто создал пропуск; заполняется сервером из сессии | пользователь пропуска |
| Переключатель компании | `tenant switcher` | В шапке кабинета, только если у человека несколько арендаторов; при одном — не показывается | выбор арендатора в форме |
| Приглашение | `invitation` | Ссылка со сроком, после перехода учётка сразу рабочая | предзапись |
| Роль | `role` | Набор атомарных прав внутри организации. Новая роль — без прав | группа прав |
| Право | `permission` | Атомарное разрешение на действие: `visit.check_in`, `pass.edit`… | доступ к модулю |
| Назначение роли | `role_assignment` | Роль пользователю в области: объект / арендатор | |
| Учётка КПП | `gate_account` | Одна на КПП. Входит устройство, не человек | учётка охранника |
| Устройство поста | `gate_device` | Компьютер/планшет, привязанный к учётке КПП токеном. Отзывается отдельно | терминал |
| Привязка устройства | `device_enrollment` | Одноразовый код/QR из админки для входа устройства | |
| Отметка смены | `shift_mark` | Необязательно: охранник выбирает себя из списка в начале смены, без PIN | смена, PIN |
| PIN старшего смены | `site.settings.senior_pin` | Необязательно: исключение прямо на посту | |
| Сессия | `session` | Серверная сессия пользователя (cookie) | токен |
