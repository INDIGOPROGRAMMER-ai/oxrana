# ADR-001. Стек

Статус: принято (10.10.2026). Подтверждает предварительный стек из `CLAUDE.md` с тремя поправками: TypeScript 7, Biome вместо ESLint + Prettier, без оркестратора сборки (см. ADR-002).

## Контекст

- `16_` B1: один движок вердикта на сервере и на посту офлайн → язык один, исполняемый в браузере.
- `16_` B8: минимум инфраструктуры — только PostgreSQL, без Redis. Хостинг в РФ, поддержка малой командой.
- Разработка идёт в облачных сессиях Claude Code: Node 22.22, pnpm 10.28, PostgreSQL 16.15 локально; Docker-демон недоступен (ADR-010).
- НФТ (`13_`): вердикт ≤ 300 мс, поиск ≤ 200 мс на 100 тыс. пропусков, офлайн поста 8 ч.

## Решение

Версии — те, что опубликованы на 10.10.2026; фиксируются в `package.json` точно (`save-exact`) и обновляются осознанно.

## Альтернативы

- **Python + FastAPI** (`13_`): отвергнуто — движок пришлось бы писать дважды (Python на сервере, JS на посту) или гонять через WASM. Нарушает B1.
- **NestJS**: отвергнуто — DI-слой и декораторы не окупаются на команде из одного-двух человек; Fastify + плагины даёт ту же структуру без магии.
- **Prisma**: отвергнуто — свой движок запросов, слабый контроль SQL (`FOR UPDATE`, advisory lock, partial/exclusion-индексы — только raw), медленный холодный старт в тестах. **Kysely**: хороший SQL-билдер, но нет генерации миграций из схемы и zod-интеграции; Drizzle даёт и схему как код, и близкий к SQL синтаксис, и `drizzle-kit generate`.
- **Redis** для счётчиков и очередей: отвергнуто (B8). Счётчики лимитов считаются по открытым визитам под блокировкой (ADR-006), очередь — pg-boss, pub/sub — `LISTEN/NOTIFY`.
- **WebSocket** вместо SSE: отвергнуто (ADR-004).
- **ESLint + Prettier**: отвергнуто в пользу Biome — одна зависимость, в 10–20 раз быстрее, правила для TS/React покрывают нужное. Если потребуется правило, которого в Biome нет, добавим ESLint точечно, не меняя формат.
- **TypeScript 5.9 вместо 7.0**: 7.0 — нативный компилятор, typecheck монорепо в разы быстрее; эмиссией JS мы не пользуемся (Vite/tsx/tsup транспилируют esbuild'ом). Риск несовместимости плагинов проверяется на этапе 1; откат на 5.9 — смена одной версии.
- **Turborepo / Nx**: отвергнуто (ADR-002).
- **Luxon / Temporal polyfill**: движок обходится `Intl` (нет зависимостей — критично для пакета, который исполняется и в браузере), UI — date-fns с пакетом поясов.
- **Нативные мобильные приложения**: отвергнуто (`01_`): PWA.

## Последствия

- Один язык и один набор схем zod: типы API, формы, OpenAPI и проверки на посте — из одного источника (`packages/contracts`).
- Развёртывание = Node-процесс + PostgreSQL + Caddy в Docker Compose на сервере объекта или в облаке (ADR-011). Никаких брокеров.
- Чистый пакет движка без зависимостей — обязательное ограничение, проверяется линт-правилом (`noRestrictedImports` на `node:*`, `Date.now`).
- Biome не форматирует Markdown/SQL — для них правил нет, читаемость контролируется в ревью.
