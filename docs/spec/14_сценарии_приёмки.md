# Сценарии приёмки

Взяты из реальных ситуаций на Радонежском и из дефектов PASS24. Каждый — кандидат в автотест: начальное состояние → действие → ожидаемый результат.

**Настройки для всех сценариев:**
- КПП-1: легковой, малотоннажный, пешеход.
- КПП-2: фура, грузовой от 10 т, спецтехника.
- Квоты:
  - ДНС: легковые 30, грузовые 25 (hard);
  - ДЛ-Транс: легковые 15 (soft, 67 ₽), грузовые 7 (soft, 233 ₽);
  - Континент: грузовые до 4,5 т — 22, фуры — 0;
  - Мастервент: грузовые — 0.
- Окно для грузовых: раньше 0 мин, позже 60 мин.

| # | Ситуация | Ожидаемый результат |
|---|---|---|
| 1 | Внутри 24 грузовые ДНС; фура ДНС с окном «сейчас» на КПП-2 | 🟢 «Грузовые 24/25»; после въезда счётчик 25/25 |
| 2 | Внутри 25 грузовых ДНС; ещё фура ДНС на КПП-2 | 🟡 «ДНС грузовые 25/25 — ждите»; кнопка «Впустить» неактивна; арендатору push «машина ждёт» |
| 3 | В сценарии 2 одна фура ДНС выезжает | На посту КПП-2 жёлтая карточка становится зелёной без F5 |
| 4 | Малотоннажный ДНС на КПП-1 при 25/25 грузовых | 🟡 — малотоннажный считается в «Грузовые», хотя едет через КПП-1 |
| 5 | Малотоннажный ДНС на КПП-2 | 🔵 «Малотоннажные — через КПП-1» |
| 6 | Фура с окном 14:00, на часах 13:40 | 🟡 «Рано: въезд с 14:00, ещё 20 мин» |
| 7 | Фура с окном 14:00–15:00, на часах 16:30 | 🔴 «Опоздание: окно закрыто в 16:00 (15:00 + 60 мин)» → «Запросить новое окно» |
| 8 | ДЛ-Транс: внутри 15 легковых, приезжает 16-я | 🟠 «Сверх лимита, 67 ₽/сутки»; визит `overage`; в отчёте сверхлимитов +1 сутки |
| 9 | Сверхлимитная машина ДЛ-Транс стоит с 22:00 до 09:00 следующего дня | Начислено 2 суток (неполные считаются полными) |
| 10 | Фура Континента | 🔴 «Фуры не предусмотрены договором арендатора (квота 0)» |
| 11 | Пешеход ДНС на КПП-2 | 🔵 «Пешеходы — через КПП-1» |
| 12 | Пешеход ДНС на КПП-1 | 🟢 — пешеход виден и пропускается (в PASS24 при КПП с типами не виден) |
| 13 | Служебный автобус ДНС (исключение) при 30/30 легковых | 🟢 «Исключение: служебный автобус», вне квоты |
| 14 | Фура X5 в 03:00 (вне рабочего времени) | 🟢 — исключение 24/7 |
| 15 | Машина без пропуска на КПП-2 | «Запросить» → арендатор получает запрос → «Оформить» → 🟢 на посту за ≤ 10 с |
| 16 | Выезд машины, въезд которой не отмечен | Найден пропуск; «Выпустить с отметкой» + причина; админу уведомление; квота не уходит в минус |
| 17 | Охранник нажал «Впустить» не той машине | «Отменить» в течение 2 мин возвращает состояние; в журнале оба события |
| 18 | Арендатор вставляет 20 строк из Excel (12 фур, 6 малотоннажных, 2 с ошибками) | Предпросмотр: 18 зелёных, 2 красных с причиной; после сохранения «создано 18 из 20» |
| 19 | Правка комментария у начавшегося пропуска на фуру | Сохраняется только комментарий; категория остаётся «фура» (в PASS24 становилась «легковой») |
| 20 | Исправление опечатки в номере у машины на воротах старшим смены | Сохраняется с причиной; в журнале «было → стало» |
| 21 | Переименование арендатора «ООО Ромашка» → «ООО Лютик» | Прошлые визиты в отчётах — «ООО Ромашка» (снимок) |
| 22 | Арендатор-администратор в Техасе создаёт пропуск «на сейчас» | Время в поясе объекта; ошибки «начало в прошлом» нет |
| 23 | Временный пропуск от арендатора без комментария | Ошибка в форме: «Укажите, для чего и зачем нужен пропуск» |
| 24 | Временный пропуск с комментарием | Уходит директору; в карточке согласования видны начало и конец; «Одобрить с изменениями» меняет конец — арендатор видит изменение |
| 25 | Разовый пропуск: въехал, выехал, вернулся через час | 🔴 «Разовый пропуск использован» → «Оформить новый» |
| 26 | Пропуск истёк, пока машина внутри | Выезд разрешён; визит помечен «после окончания»; уведомление |
| 27 | Белорусский номер «1234 AB-7» | Нормализован в `1234AB7`, страна BY, поиск по «1234» находит |
| 28 | Кириллический «Е121УР174» и латинский «E121YP174» | Один и тот же номер |
| 29 | Интернет на посту пропал на 30 мин, 5 въездов | Въезды отмечены по кэшу, синхронизированы после связи; квоты пересчитаны |
| 30 | Мастервент: малотоннажный | 🔴 «Грузовые не предусмотрены договором» |
| 31 | Охранник нажимает «Исключение» без права | Кнопки нет; у старшего смены — есть, с обязательной причиной и уведомлением |
| 32 | Удаление КПП, у которого есть правила маршрута | Предупреждение «используется в 4 правилах», мягкое удаление |
