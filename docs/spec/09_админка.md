# Админка оператора объекта

## Мастер первичной настройки

Каждый шаг — с понятными значениями по умолчанию и предпросмотром «что увидит охранник».

1. **Объект:** название, адрес, часовой пояс (определяется по адресу), рабочее время комплекса.
2. **КПП:** список, часы работы.
3. **Категории транспорта:** готовый набор для логистики с возможностью переименовать («малотоннажный» → «Газель»).
4. **Маршруты:** матрица «категория × КПП» с галочками, отдельная строка «Пешеход».
5. **Доки и зоны:** номера доков массово («1–72»), зоны парковки.
6. **Арендаторы:** импорт из XLSX или по одному; договор и PDF.
7. **Назначения и квоты** по каждому арендатору:
   - доки — диапазоном номеров; квота грузовых по умолчанию = число доков;
   - места; квота легковых;
   - режим hard / soft / warn, тариф;
   - пункт договора-основание.
8. **Политики:** окна времени (допуски), сроки пропусков, согласование.
9. **Люди:** сотрудники и роли; пользователи арендаторов (приглашения).
10. **Устройства КПП:** QR-привязка.
11. **Проверка:** «тестовый прогон» вердиктов на примерах:
    - фура ДНС на КПП-1 → синий;
    - 26-я фура ДНС → жёлтый;
    - и так далее.

## Экраны

- **Монитор:** кто внутри, по арендаторам и группам; ожидающие у ворот; отказы за сегодня; переопределения.
- **Арендатор (карточка):**
  - договор;
  - назначения (доки, места) с историей;
  - квоты с основанием;
  - исключения;
  - пользователи;
  - статистика.
- **Пропуска:** поиск по всему, массовые действия, согласования (очередь с полной карточкой будущего пропуска, «одобрить с изменениями»).
- **Журнал КПП:** все вердикты, включая отказы, «не тот КПП» и переопределения.
- **Нарушения:** реестр, акты PDF, статусы.
- **Отчёты:**
  - заполненность по часам и дням;
  - время на территории;
  - отказы и причины;
  - сверхлимиты по форме прил. 4 ДЛ-Транса;
  - выгрузка для 1С;
  - активность охраны по сменам.
- **Аудит:** изменения настроек, квот, пропусков — «было → стало».

## Правила качества админки

- Любая ошибка называет причину и даёт ссылку на настройку.
- Удаление — мягкое, с показом ссылок («используется в 12 пропусках и 1 квоте»).
- Переименование не меняет историю.
- Опасные операции — блокировка арендатора, смена квоты посреди дня — показывают последствия: «сейчас внутри 3 машины, они смогут выехать».
- Блокировка арендатора — режимы:
  - «запретить новые пропуска»;
  - «запретить въезд»;
  - «полная» (выезд разрешён всегда).
