# Своя платформа пропускного режима — пакет для старта

**Цель.** Сделать свою платформу управления въездом на территорию: тот же класс задач, что PASS24.online, но понятнее, с более тонкими настройками и без обходных путей. Главный пример: в PASS24 приходится заводить арендатору по два адреса, чтобы раздельно считать лимиты легковых и грузовых.

**Источник требований** — реальное внедрение PASS24 на складском комплексе ЛЦ «Радонежский» (Челябинск, ул. Радонежская, 15) для ООО «Интеграция» в августе–октябре 2026. Всё ниже взято из этого опыта: договоры арендаторов, работа охраны на двух КПП, дефекты PASS24, найденные на живом стенде.
