# Функции по модулям

Метки: **[MVP]** — нужно для запуска на Радонежском вместо PASS24; **[v2]** — следующий этап; **[v3]** — позже.

## 1. Объект и инфраструктура

- [MVP] Объект: название, адрес, часовой пояс, рабочее время, контакты, логотип.
- [MVP] КПП: название, направление, часы работы, устройства.
- [MVP] Зоны и здания; доки (номер, зона, тип); парковочные участки (мест, разметка).
- [MVP] Справочник категорий транспорта и групп для квот, с переопределением на объекте.
- [MVP] Правила маршрута «категория / пешеход → КПП» в виде матрицы с галочками.
- [v2] Схема территории: загрузка картинки плана, отметки КПП, доков и зон. Используется на странице водителя и в отчётах.
- [v3] Несколько объектов у одного оператора, общий чёрный список организации.

## 2. Арендаторы и договоры

- [MVP] Карточка арендатора: реквизиты, короткое имя, контакты (ответственный, экстренный телефон из Правил), статус.
- [MVP] Договор: номер, дата, срок, PDF, пункты-основания.
- [MVP] Назначения: помещения, доки (номера), парковочные места — со сроками.
- [MVP] Квоты на арендатора: по группам, режим hard / soft / warn, тариф сверхлимита, основание.
- [MVP] Исключения: автобус, 24/7, руководство.
- [MVP] Пользователи арендатора: приглашение по e-mail или SMS, роли внутри арендатора.
- [v2] Напоминание об окончании договора; авто-архив после срока.
- [v2] Мастер «из договора в настройки»: выбираешь пункты — получаешь квоты.

## 3. Пропуска

- [MVP] Типы: разовый (до N часов, один въезд), многоразовый (интервал), постоянный.
- [MVP] Участник: машина (номер + страна + категория + марка необязательно) или пешеход (ФИО).
- [MVP] **Окно прибытия** для грузовых: обязательное, с допуском.
- [MVP] **Пакетное создание.** Таблица на экране, вставка из Excel или письма; каждая строка — номер, категория, марка, водитель, время; предпросмотр; итог «создано N из N».
- [MVP] Шаблоны из автопарка: «завтра как обычно» — повтор вчерашних пропусков.
- [MVP] Согласование по политике: разовый — сразу; временный и постоянный — директор ЛЦ. Комментарий обязателен. «Одобрить с изменениями».
- [MVP] Редактирование с журналом и причиной; правка номера у машины на воротах.
- [MVP] Закрытие и отмена пропуска; массовое закрытие.
- [MVP] Страница водителя по ссылке или QR: номер, окно времени, **на какой КПП ехать**, адрес и схема, телефон поста. Токен со сроком действия.
- [MVP] Нормализация номера (кириллица/латиница, регистр, пробелы, тире), иностранные форматы.
- [v2] Слоты доков: бронирование окна разгрузки на конкретный док, контроль пересечений.
- [v2] Приглашение: гость сам заполняет номер и ФИО по ссылке.
- [v3] Повторяющиеся пропуска по расписанию: каждый вторник 08:00–10:00.

## 4. Пост охраны

- [MVP] Вход устройства один раз (привязка к КПП QR-кодом от админа), PIN охранника на смену.
- [MVP] Поиск по цифрам номера или фамилии; автоочистка после действия.
- [MVP] **Вердикт-светофор** с одной большой кнопкой (`07_экран_охраны.md`).
- [MVP] Счётчики заполненности: по арендаторам и группам для своего КПП.
- [MVP] «Машина без пропуска» → запрос арендатору / админу → ответ на экране поста.
- [MVP] «Отказать» с выбором причины (фиксируется в журнале).
- [MVP] Переопределение вердикта с правом и причиной.
- [MVP] Встроенное «Что делать если» и телефон дежурного администратора.
- [MVP] Работа при плохом интернете: кэш пропусков на сутки, очередь действий, предупреждение «нет связи».
- [v2] Сканер QR (камера планшета или USB-сканер).
- [v2] Фиксация нарушения с фото → черновик акта.
- [v2] Журнал смены и передача смены.
- [v3] Камера распознавания номеров: карточка открывается сама; кнопка «Впустить» открывает шлагбаум.

## 5. Кабинет арендатора (веб + PWA)

- [MVP] Мои пропуска: список, фильтры, статусы, кто сейчас внутри.
- [MVP] **Виджет квоты:** «Легковые 12/30 · Грузовые 20/25», очередь ожидающих у ворот.
- [MVP] Создание одиночное и пакетное; автопарк; шаблоны.
- [MVP] Уведомления: машина въехала / выехала / стоит у ворот без пропуска (с кнопкой «Оформить») / отказ на КПП / превышение норматива времени. Каналы — e-mail, push PWA, Telegram.
- [MVP] Выгрузка истории сразу файлом (XLSX/CSV), любой период.
- [MVP] Ответы на запросы с поста: «машина на воротах — подтвердить?».
- [v2] Telegram-бот для заказа разового пропуска и ответов охране.
- [v2] Сотрудники арендатора с ролями: заказчик / наблюдатель / ответственный.

## 6. Администрирование

- [MVP] Мастер настройки объекта: объект → КПП → категории → маршруты → арендаторы → квоты → пользователи → устройства КПП.
- [MVP] Роли и права (`06_роли_и_права.md`).
- [MVP] Журнал аудита с поиском.
- [MVP] Монитор объекта в реальном времени: кто внутри, заполненность квот, ожидание у ворот, отказы.
- [MVP] Импорт из PASS24: пропуска, пользователи, адреса — через выгрузки PASS24 (XLSX).
- [v2] Отчёты:
  - заполненность по часам;
  - простой (время на территории) по арендаторам и категориям;
  - отказы и причины;
  - сверхлимиты для счёта (форма прил. 4 ДЛ-Транса);
  - нарушения и акты.
- [v2] Шаблоны писем и уведомлений арендаторам.
- [v3] Конструктор отчётов, расписание отправки.

## 7. Нарушения и начисления

- [v2] Типы нарушений из Правил с суммой штрафа и пунктом.
- [v2] Акт нарушения: PDF по шаблону, подписи, статус, спор.
- [v2] Сверхлимит: автоматическое начисление по мягким квотам, сутки × тариф, выгрузка в 1С или XLSX.

## 8. Интеграции

См. `12_интеграции_и_API.md`.
- [MVP] REST API для своих клиентов: веб, PWA, бот.
- [v2] Вебхуки.
- [v3] Камеры номеров, шлагбаумы, СКУД, 1С.
