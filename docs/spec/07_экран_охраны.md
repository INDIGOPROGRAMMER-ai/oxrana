# Экран поста охраны

Пользователь — охранник, который почти не работает с компьютером. Сейчас для него сделаны PDF на 5 страниц и отдельная программа «Что делать если» (в PASS24-архиве, в репозиторий не перенесена; описание — `../reference/охрана_как_сейчас_в_PASS24.md`). Цель новой платформы: **обучение — 5 минут, без бумажных инструкций.**

## Устройство и вход

> **Изменено:** одна учётная запись на КПП, личных PIN охранников нет — см. `16_дополнения_и_уточнения.md`, A11. Пункты ниже про выбор себя и PIN — устаревшие (остались как необязательная настройка «отметка смены»).

- Компьютер или планшет КПП привязывается к КПП один раз: админ показывает QR-код или вводит код устройства. Устройство получает долгоживущий токен и не разлогинивается.
- Охранник начинает смену: выбирает себя в списке и вводит PIN из 4 цифр. Все действия смены подписаны им.
- Если связь пропала, вверху жёлтая полоса «Нет связи — работаем по сохранённым данным». Действия встают в очередь и отправляются, когда связь вернётся.
- Шрифт крупный, кнопки не меньше 64 px, масштаб под сенсорный экран.

## Цвета вердикта

| Цвет | Что значит | Кнопка | Текст причины (пример) |
|---|---|---|---|
| 🟢 зелёный | можно | ВПУСТИТЬ / ВЫПУСТИТЬ | — |
| 🟡 жёлтый | надо подождать | неактивна, вместо неё «Ждать» | «Рано: въезд с 14:00, ещё 25 мин» · «ДНС грузовые 25/25 — ждите, пока выедет машина» |
| 🔵 синий | не этот КПП | «Направить на КПП-2» (фиксирует событие) | «Фура — только через КПП-2» · «Пешеходов через КПП-2 не пускают» |
| 🔴 красный | нельзя | «Отказать» | «Чёрный список: …» · «Пропуск закончился вчера в 23:59» · «Грузовые не предусмотрены договором арендатора» |
| 🟠 оранжевый | можно, но с отметкой | ВПУСТИТЬ (сверх лимита) | «ДЛ-Транс легковые 15/15 — сверх лимита, доплата 67 ₽/сутки» |

- Переопределение (впустить при жёлтом или красном) — маленькая ссылка «Исключение» только у старшего смены. Обязательна причина, уведомление уходит админу.
- После «Впустить» или «Выпустить»:
  - карточка на 2 секунды показывает «✔ Въезд отмечен 14:32 — открывайте шлагбаум»;
  - поиск очищается сам;
  - позже — шлагбаум открывается сам.

## Сценарии одной кнопкой

1. **Машина без пропуска.**
   1. Ввести номер и выбрать арендатора (список с крупными названиями), категорию.
   2. Нажать «Запросить».
   3. Арендатору приходит push и Telegram: «На КПП-2 фура А123ВС174, оформить?».
   4. На экране поста таймер ожидания и статус ответа.
   5. Одобрили — карточка становится зелёной. Отказали или нет ответа за N минут — «Не пускать», можно позвонить ответственному (номер на экране).
2. **Выезжает, а пропуска нет или въезд не отмечен.** Система сама ищет закрытые, просроченные и чужие пропуска, показывает найденное. Охранник выбирает «Выпустить с отметкой» и причину; админ получает уведомление. Вместо «поставьте галочки Просрочен и Закрыт и позвоните администратору».
3. **Нажал не ту кнопку.** Кнопка «Отменить последнее действие» действует 2 минуты, пишется в журнал.
4. **Арендатор говорит «пропуск есть, а вы не видите».** Обновление идёт в реальном времени, F5 не нужен. Поиск идёт по всем пропускам объекта, а не только «своим». Если пропуск на другой КПП — синий вердикт с подсказкой.

## Табло заполненности

Отдельная вкладка «Табло», крупно:

```
ДНС Ритейл        Легковые 12/30   Грузовые 25/25 ⏳ 2 ждут
Рельеф-Центр      Легковые  1/2    Грузовые 11/18
ДЛ-Транс          Легковые 16/15 ⚠ сверх 1   Грузовые 5/7
X5                Легковые  0/2    Грузовые  6/7  (24/7)
…
```

## Встроенная помощь

- Кнопка «Помощь» — те же ситуации, что в программе «Что делать если», но со ссылкой прямо в нужное действие.
- Телефон дежурного администратора (задаётся в настройках объекта) всегда виден внизу.

## Что охраннику больше не нужно делать

| Сейчас в PASS24 | В новой платформе |
|---|---|
| Пересчитывать московское время в местное | Всё в местном времени |
| Помнить, какие типы на каком КПП | Синий вердикт «не ваш КПП» |
| Считать машины арендатора на территории | Квота в вердикте и на табло |
| Сверять «Начало» пропуска с часами | Жёлтый вердикт «рано» |
| Очищать поиск, следить за галочками | Автоочистка, фиксированный вид |
| Копировать пароль из программы | Устройство не разлогинивается |
| Звонить, если пропуска нет | Кнопка «Машина без пропуска» |
| Отдельно открывать шлагбаум | Позже — автоматически |
