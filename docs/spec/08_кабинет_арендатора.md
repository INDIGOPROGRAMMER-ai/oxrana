# Кабинет арендатора

Веб-кабинет (основной, для логиста за компьютером) плюс та же версия на телефоне (PWA). Вход по e-mail или телефону и паролю либо по коду из SMS. Приглашение приходит со ссылкой — учётка рабочая сразу, а не «предзапись», как в PASS24.

## Главная

```
ДНС Ритейл · ЛЦ «Радонежский»                           Петров А. ▾
┌──────────────────────────┐ ┌──────────────────────────┐
│ Легковые на территории   │ │ Грузовые (доки)          │
│        12 / 30           │ │    25 / 25   ⏳ 2 ждут    │
└──────────────────────────┘ └──────────────────────────┘
Сегодня: ожидаются 18 · въехали 31 · выехали 27 · отказов 1
[+ Пропуск]  [+ Несколько]  [Автопарк]  [История]
```

## Создание пропуска

- **Одна форма для всех случаев.**
  - Выбрать «Машина» или «Пешеход».
  - Указать номер, категорию (без дефолта или с дефолтом арендатора), марку (необязательно).
  - Выбрать тип пропуска (разовый / многоразовый / постоянный).
  - Время: окно прибытия обязательно для грузовых.
  - Комментарий: обязателен для многоразовых и постоянных — «для чего и зачем».
- **Подсказки сразу в форме**, а не после сохранения:
  - «Фура → КПП-2»;
  - «Грузовые сейчас 25/25 — машина будет ждать у ворот»;
  - «Временный пропуск уйдёт на согласование директору ЛЦ».
- **Время** вводится и показывается в местном поясе объекта, с подписью «Челябинск, UTC+5».
- **Нет понятия «адрес легковые / грузовые»**: система сама относит машину к квоте по категории.

## Пакетный ввод

- Таблица на экране:

  | Номер | Категория | Марка | Водитель | Окно прибытия | Комментарий |
  |---|---|---|---|---|---|

- Можно вставить скопированные из Excel или письма строки: номера распознаются, кириллица и латиница приводятся к одному виду, иностранные номера определяются по формату.
- Разные категории в одной пачке — нормально.
- Перед сохранением — предпросмотр: зелёные строки, красные с причиной («номер в чёрном списке», «формат не распознан»).
- После сохранения — итог «создано 18 из 20, 2 с ошибками» и список ошибок.

## Автопарк и шаблоны

- Постоянные машины арендатора: номер, категория, марка, водитель. Из автопарка пропуск создаётся в один клик.
- «Повторить вчерашний день», шаблон «утренняя развозка».

## Согласование

- Статусы заявок видны: «на согласовании у директора ЛЦ», «одобрено с изменениями: …», «отклонено: причина».
- Push или письмо о решении.

## Уведомления (настраиваются)

- Машина въехала / выехала.
- Машина ждёт у ворот: квота заполнена или рано.
- **Машина у ворот без пропуска** — кнопки «Оформить» и «Отклонить».
- Отказ на КПП с причиной.
- Превышение норматива времени на территории.
- Сверхлимит: для мягких квот, с суммой.

## История и отчёты

- Все пропуска и визиты, фильтры, поиск; скачать XLSX или CSV сразу.
- Время на территории по каждой машине; простой.
- Для мягких квот — сверхлимиты по дням с суммами, совпадающие со счётом.
