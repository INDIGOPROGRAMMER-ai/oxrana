# MVP, этапы, стек

## Цель MVP

Заменить PASS24 на ЛЦ «Радонежский» для повседневной работы:
- арендаторы заказывают пропуска;
- охрана на двух КПП впускает и выпускает по вердикту;
- оператор видит заполненность и разбирает исключения.

Квоты всех 11 арендаторов — без обходных путей.

## Состав MVP

1. Объект, КПП, категории, маршруты, доки и зоны, рабочее время, часовой пояс.
2. Арендаторы, договоры (PDF + пункты), назначения доков и мест, квоты hard/soft/warn, исключения (автобус ДНС, X5 24/7).
3. Пропуска: разовый / многоразовый / постоянный, машина / пешеход, окно прибытия, пакетный ввод, автопарк, согласование, редактирование с журналом, страница водителя.
4. Пост охраны: привязка устройства, PIN смены, поиск по цифрам, вердикт-светофор, табло, «машина без пропуска», выезд без отметки, отмена действия, офлайн-кэш.
5. Кабинет арендатора: квоты вживую, пропуска, история и выгрузка, уведомления (e-mail + push).
6. Админка: мастер настройки, монитор, журнал КПП, аудит, роли.
7. Отчёты: сверхлимиты (ДЛ-Транс), время на территории, отказы.
8. Импорт из PASS24.

## Рекомендуемый стек (решение за тобой)

- **Бэкенд:** Python + FastAPI либо TypeScript + NestJS; PostgreSQL 16 (+ pg_trgm для поиска номеров); Redis — кэш счётчиков квот и очередь; фоновые задачи (Celery/RQ или BullMQ).
- **Реальное время:** WebSocket или SSE.
- **Фронтенд:** React + TypeScript, один код для админки, кабинета и поста; PWA с офлайн-кэшем (IndexedDB) для поста.
- **Хостинг:** в РФ (Yandex Cloud, Selectel, VK Cloud) — персональные данные граждан РФ (ФИО, телефоны, госномера) подпадают под 152-ФЗ, нужна локализация.
- **Почта, SMS:** российские провайдеры.
- **Мониторинг:** Sentry / Grafana; резервные копии БД ежедневно.

## Нефункциональные требования

- Вердикт на посту — до 300 мс; поиск по номеру — до 200 мс на 100 тыс. пропусков.
- Пост работает офлайн минимум 8 часов (смена) по кэшу.
- Журнал аудита неизменяемый; хранение не меньше 3 лет (уточнить юридически).
- Доступность 99,5 % в рабочее время; круглосуточно — для объектов 24/7 (X5).
- Роли и права проверяются на сервере, а не только скрытием кнопок.
- Время везде в поясе объекта, тесты на смену пояса.
- Интерфейс на русском; термины — по единому словарю.
