Формат: контекст → варианты → **рекомендация** → что блокирует. Пока ответа нет, работа идёт по рекомендации с пометкой `ПРОВЕРИТЬ` в коде. В демо-данных пометок нет: реальные данные объекта вводит заказчик сам (ADR-016). Закрытые вопросы — в разделе F с датой и решением.
